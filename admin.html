📖 How to onboard a new client
Step 1 — Create the org
Go to the "Create Org" tab, fill in the org name and code. Credentials are optional — client can fill them via the setup page.
Step 2 — Send URLs to client
Send them the App URL to use the app, and the Setup URL to configure their Jira/ADO credentials.
App URL: https://aidefectagent.vercel.app?org=clientcode
Setup URL: https://aidefectagent.vercel.app/setup?org=clientcode
Step 3 — Client fills credentials
Client opens the Setup URL, enters their Jira/ADO/GitHub tokens. They are stored securely in the database — you never see them.
Step 4 — Client starts using
Client opens the App URL, creates tickets. All tickets go to THEIR Jira/ADO automatically.
